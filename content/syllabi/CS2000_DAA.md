# CS2000 — Design and Analysis of Algorithms (2026–27)

B.Tech. (Hons) CSE · Major (Core) · 4 credits (2:1:2) · 30L + 15T + 30P

Source: `CS2000_DAA_Syllabus_2026_27.pdf`

## Module 1 (9h)
Introduction to Algorithms, Asymptotic notation and growth of functions, Analyzing complexity of algorithms, Recurrence relation, Substitution method, Recursion Tree Method, Master’s Theorem, Brute force Design Technique Linear Search, Sorting methods: Bubble sort, Insertion Sort, and Selection Sort.

## Module 2 (9h)
Divide & Conquer: Merge Sort, Quick Sort, Strassen’s Matrix Multiplication. Decrease & Conquer: Binary Search, Heap Sort, DFS, BFS and Counting Sort.

## Module 3 (9h)
Elements of greedy strategy, Knapsack problem, Job sequencing with deadlines, Huffman encoding. Spanning trees, Minimum cost spanning trees: Kruskal’s and Prim’s algorithms; Single source shortest path algorithms, Dijkstra’s Algorithms.

## Module 4 (9h)
Elements of dynamic programming: 0/1 Knapsack, Matrix chain multiplication, longest common subsequence, Bellman-Ford Algorithm, Floyd Warshall’s algorithm.

## Module 5 (9h)
Backtracking: N-Queens problem, Hamiltonian Cycle. Branch & Bound: Knapsack Problem. String matching: Rabin-Karp, Knuth-Morris-Pratt. NP-completeness: P, NP, NPC, NPH.

## Labs (not taught as templates — implementation is a way to go deep)
Binary search, min/max by D&C, merge sort, quick sort, heap sort, BFS, DFS, greedy knapsack, Prim, 0/1 knapsack DP, all-pairs shortest path, N-Queens.
